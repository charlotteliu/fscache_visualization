How does S3-FIFO work?

Simple and Scalable caching with three Static FIFO queues: a small filter queue, a main cache queue, and a ghost queue that remembers recent evictions.

1. Cache hit

If an object is in S or M, S3-FIFO increments its small access counter. No LRU-style list promotion is required.

2. New miss

If the key is not remembered by G, it is inserted into S. When S is full, cold entries are moved to G.

3. Ghost miss

If the key appears in G, S3-FIFO treats it as a likely reusable object and inserts it into M.

4. Main eviction

M evicts in FIFO order; touched entries get one more chance by reinsertion with a decremented counter.
